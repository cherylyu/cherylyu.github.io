# [cherylyu.github.io](https://cherylyu.github.io/)

A modern portfolio website showcasing my web development projects and skills. Built with a clean, responsive design featuring smooth animations and interactive elements.

## Tech Stack

- **Framework**: Nuxt.js 3
- **Styling**: Tailwind CSS
- **Deployment**: GitHub Pages

## Setup

Make sure to install dependencies:

```bash
npm install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
npm run dev
```

## Production

Build the application for production:

```bash
npm run build
```

Locally preview production build:

```bash
npm run preview
```
